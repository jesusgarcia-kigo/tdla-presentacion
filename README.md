# TDLA · Una mini app en Kigo

Presentación web del uso de la mini app del Torneo de la Amistad 2026.

- `index.html`: versión con scroll (scrollytelling).
- `diapositivas/index.html`: la misma historia en diapositivas (flechas, clic o deslizar).
- `img/`: logos y capturas.

Se publica con GitHub Pages en cada push a `main`.
